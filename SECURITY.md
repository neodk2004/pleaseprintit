# Sicherheit / Security

**Deutsch:** Bitte melde Sicherheitslücken nicht als öffentliches Issue, sondern vertraulich über **[Security → Report a vulnerability](https://github.com/neodk2004/pleaseprintit/security/advisories/new)**. Unterstützt wird jeweils der aktuelle Stand von `main`.

**English:** Please do not report security vulnerabilities as public issues. Use **[Security → Report a vulnerability](https://github.com/neodk2004/pleaseprintit/security/advisories/new)** instead. Only the latest version on `main` is supported.
